# {{name}}

Started from **creative-kit** (`~/projects/creative-kit`), Petra's library of building blocks for creative sites.

## Stack
- Vite + React + TypeScript, Tailwind CSS v4, GSAP (+ ScrollTrigger, SplitText, Draggable), Lenis smooth scroll
- Package manager: pnpm

## Conventions
- `@/` maps to `src/`
- Theme tokens live in `src/styles/theme.css` (generated by `pnpm kit theme <id> --to .` in the kit; edit freely afterwards)
- Style with theme tokens, not raw colours: `bg-paper`, `text-ink`, `bg-accent`, `bg-mist`, `text-muted`, `text-display` / `text-headline` / `text-title` / `text-lead`, `font-display`, `font-mono`, `rounded-kit`, `ease-out-expo`, `.caption`
- Kit blocks are copied into `src/components/kit/<block>/` and helpers into `src/lib/kit/`. They're this project's code now: change them as needed
- Always import gsap from `@/lib/kit/gsap`; call `initLenis()` once in App

## Adding blocks
From the kit folder: `pnpm kit add <block...> --to <this folder> --install`. See the kit's site (`pnpm dev` in creative-kit) for every block with live demos.

## Concept
If `concept/CONCEPT.md` exists, it's the site's direction (made with the kit's `site-concept` skill). Follow its principles and kit map, and rework kit blocks the way it says rather than using them as they are.

## Inspiration
Decisions, references and rejected ideas for this site belong in creative-kit's inspo library: `content/inspo/` with a project entry in `content/projects.json`.
